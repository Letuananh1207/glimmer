# Kế hoạch: áp thiết kế 2026-11-26.6 — màn thiết bị chạm được như Windows XP

- Ngày: 2026-11-26 · Nguồn: `/ui-apply`, `design/CHANGELOG.md` mục 2026-11-26.6
- Người dùng chốt (2026-11-26): (1) đổi luật như thiết kế đề xuất; (2) **cách A** — dùng API firmware đã có;
  (3) soạn phiếu `/panel-design` cho phần máy chưa vẽ.

## Cách A: app là "máy tính", thiết bị là màn hình

App tự hiểu chỗ chạm (app vẽ ô màn nên biết chạm trúng gì) và đổi ra lệnh firmware đã có:

| Chạm | Lệnh gửi | App giữ |
| --- | --- | --- |
| biểu tượng desktop / mục Start / Tất cả chương trình | `POST /api/channel {name}` | cửa sổ lên trên cùng |
| nút thanh tác vụ (skill) | cửa sổ gần nhất của skill đó (hoặc kênh đầu, như nhảy tab cũ); đang trên cùng → thu nhỏ (như XP) | |
| `_` | `{name: "Home"}` (desktop) | cửa sổ vẫn trong danh sách, đánh dấu thu nhỏ |
| `×` | cửa sổ trước đó chưa thu nhỏ, hết → `Home` | bỏ cửa sổ khỏi danh sách |
| `□` | không gửi (cửa sổ trên máy luôn phóng to) | |
| giữ (chuột phải) | không gửi — menu chưa có thiết kế (phiếu panel) | |
| start | mở `StartMenuSheet` (chỉ ở app) | |

- Không tự xoay: màn mở ra đọc `/api/settings`, `autoRotate` còn `true` → gửi `{autoRotate: false}` một lần.
- Ô màn vẽ **đúng như máy** (desktop hiện có: Claude, Codex, Ảnh, Thùng rác). Biểu tượng cho mọi skill, trạng thái
  "vừa cài", cửa sổ thu nhỏ trên máy, menu chuột phải: chờ `/panel-design`
  (`docs/phieu_panel/2026-11-26-desktop-cua-so-xp.md`), không vẽ tạm.

## Nhiệm vụ

1. **Luật** `docs/testing/quy_tac.md`: R-SK-2 đổi; R-DK-3 đổi theo lệnh mới; R-DK-4 bỏ; thêm R-DK-7…10.
2. **Domain**: `domain/models/windows.dart` (`WindowStack`: mở / thu nhỏ / tắt / theo thiết bị, R-DK-7/8);
   `domain/rules/touch_rules.dart` (`touchTargetAt`: toạ độ px máy → đích, vùng trúng nới 44 dp);
   `control_rules.dart` (`programsOf`: chương trình theo skill bật, R-DK-9; bỏ `rotationGuess`/`stepChannel`/tiến độ slide);
   `ControlCommand` / `ControlCaps` (thêm `touch`, bỏ prev/next/pause/resume); use case `open(name)`, `stopRotation()`.
3. **ViewModel**: bỏ step / pause / tiến độ; thêm `tap(Offset)`, `hold`, `openProgram`, `openSkill`, `desktop`,
   `restart`; chip trạng thái theo lệnh.
4. **Giao diện**: `TouchMirror` (thay `DeviceMirror`, vỏ 376 / màn 360 ×1.5), `TapRipple`, `StatusChip`,
   `ChannelLine` (thay `ChannelProgress`), `TouchLegend`; bỏ `ControlPad`, `JumpTabBar`; `StartMenuSheet`,
   `AllProgramsSheet`; thanh tác vụ của ô màn bỏ vạch tiến độ. Token `app_text.dart`.
5. **Điều hướng**: Start → Cài đặt / Skill / Thiết bị (tab), Số liệu (push), Khởi động lại (hỏi lại → `/api/reboot`).
6. **Test**: luật (mã R-…), ViewModel, widget; `check.dart --changed`, `flutter analyze`, `flutter test`.

## Chờ / ghi lại

- Firmware vẫn có `slide_ms` / pause; app không dùng nữa. Thanh tác vụ trên máy còn vạch tiến độ → phiếu panel.
