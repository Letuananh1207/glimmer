1. **Bỏ nút "Tắt màn" trên app** — tắt = nút nguồn (R-DK-20). `/api/screen` vẫn còn ở firmware (thẻ agent đánh thức).
2. **Bỏ Start / Tất cả chương trình của app** (R-DK-9, R-DK-15): Start mở trên thiết bị bằng phím Windows / click nút
   start. Kéo theo: luật click mục Start trên thiết bị (mới, R-DK-22). Mục cột phải trên máy (Số liệu, Cài đặt, Thêm /
   gỡ, Thiết bị) là màn **của app** → click vào đó trên thiết bị mở màn tương ứng trên điện thoại? Khởi động lại / Tắt
   màn ở dải dưới Start → Khởi động lại (hỏi lại như cũ) / Tắt = nút nguồn?
3. **Rung nhẹ** mỗi click / phím / nút chuột (thêm vào R-DK-18/19).
